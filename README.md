# 미니 CD 케이스 공방

그림을 올려 칸에 맞추고, 뒷면 접는 부분에 색과 글자를 넣어 **A4 실제 크기 PDF**로 받는 미니 CD 케이스 인쇄 도구입니다.

바로 쓰기: https://techkwon.github.io/mini-cd-case-maker/

## 크기 (mm)

| 칸 | 크기 | 비고 |
|---|---|---|
| 앞커버 | 84×42 | 가운데 접음. 왼쪽 42×42 = 안쪽 면, 오른쪽 42×42 = 앞면 |
| 뒷면 | 65×39 | 왼쪽 5mm 접힘(0~5), 가운데 그림 50×39(5~55), 오른쪽 5mm씩 두 번 접힘(55~60, 60~65) |
| CD | 지름 39 | 가운데 구멍 지름 5 |

## 쓰는 법

1. 크기 확인: 「크기」 탭에서 칸 가로·세로, 접는 폭, CD 지름을 mm로 바꿀 수 있습니다. A4 한 장을 넘는 값은 적용되지 않습니다.
2. 칸 고르기: 전체 배치에서 칸을 누르거나 위 탭을 누릅니다.
3. 그림 넣기: 「이 칸에 그림 넣기」를 누르거나 그림 파일을 편집 창에 끌어다 놓습니다.
4. 맞추기: 한 손가락으로 끌어 옮기고, 두 손가락으로 벌려 확대합니다. 컴퓨터에서는 마우스 휠과 화살표 키도 됩니다.
5. 글자 넣기: 그림 칸마다 「+ 이 칸에 글자 추가」로 글자를 얹고 크기·색·글꼴·굵게·테두리를 정합니다. 글자는 편집 창에서 끌어 옮기고 두 손가락으로 크기를 바꿉니다.
6. 접는 부분: 「접는 부분」 탭에서 칸마다 배경색, 글자, 글자색, 글자 방향을 정합니다.
7. 「A4 PDF 받기」를 누르고, 인쇄할 때 배율을 **100%(실제 크기)** 로 맞춥니다.

그림은 자르는 선 밖으로 1mm 더 그려져서 가위질이 조금 빗나가도 흰 틈이 생기지 않습니다. 올린 그림은 브라우저 안에서만 쓰이고 어디로도 보내지지 않습니다.

## 만든 방법

HTML 파일 하나(`index.html`)이고, PDF는 [jsPDF](https://github.com/parallax/jsPDF) 2.5.1(cdnjs)로 만듭니다. 글꼴은 Google Fonts의 IBM Plex Sans KR, Black Han Sans, Nanum Myeongjo, Gaegu, Space Grotesk입니다.
